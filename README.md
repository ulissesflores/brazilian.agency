# brazilian.agency

Portal da Open Source Brazilian Intelligence Agency: inteligência de fontes abertas sobre política e dados do Brasil. Projeto independente, sem vínculo com governo ou órgão público. Site estático (GitHub Pages). O dossiê 001 é a página `output/raio-x.html` do repositório [brazil-governments-factcheck](https://github.com/ulissesflores/brazil-governments-factcheck) (DOI 10.5281/zenodo.23604103), copiada a cada versão.
